# Genians-Capstone

## Credit union network access readiness check (demo)

A clickable prototype of a self-check landing page for credit union IT teams. Visitors answer 10 questions about how devices get onto their network. They get a score out of 100, their biggest gaps, and the rule each gap traces back to.

## Live page

https://taeyunkim03.github.io/Genians-Capstone/

## What's in here

- `index.html` is the whole page. HTML, CSS and JavaScript are in one file, so there's no build step.

## Status

- Student capstone prototype. "Demo" is a placeholder name.
- The email form doesn't send or store anything.
- There's no analytics yet.

## Where the questions come from

Each question maps to one or more of these. Links are at the bottom of the page.

- NCUA 12 CFR Part 748, Appendix A
- FFIEC IT Examination Handbook, Information Security booklet (2016), section II.C.9
- NIST Cybersecurity Framework 2.0
- CIS Critical Security Controls v8.1
